Build a complete, modern, single-page Subtitle (.SRT) Translator Web Application that runs entirely in the browser without requiring any database or complex backend setup.

### CORE WORKFLOW & UI REQUIREMENTS:
1. **Configuration Panel:**
   - **Google Gemini API Key Input:** A password-style input field (with show/hide toggle and localStorage save option) where the user enters their key from Google AI Studio.
   - **Model Selector Dropdown:** 
     - `gemini-3.5-flash-lite` (Default - Best for High Volume: 500 RPD / 15 RPM)
     - `gemini-3.1-flash-lite` (High Volume Alternative: 500 RPD / 15 RPM)
     - `gemini-3.8-flash` (Highest Quality: 20 RPD / 5 RPM)
     - `gemini-3.7-flash` (High Quality: 20 RPD / 5 RPM)
     - `gemini-2.5-flash` (Standard: 20 RPD / 5 RPM)
     - Plus a "Custom Model ID" option where the user can type a model name manually if needed.
   - **Target Language Selector:** Default selected value MUST be **"Sinhala (සිංහල - Natural Spoken/Conversational)"**. Also include options for "Sinhala (Formal)", "Tamil", "Hindi", "Spanish", "French", and a "Custom Language" text input.
   - **Chunk Size & Delay Settings:** Default chunk size = 60 subtitle blocks per request. Auto-set delay between requests based on model (4 seconds for Flash Lite models, 12 seconds for 3.8/3.7/2.5 Flash models to respect RPM limits), with ability for user to adjust.

2. **File Upload:**
   - A clean drag-and-drop zone to upload an English `.srt` file.
   - Once uploaded, immediately parse the `.srt` file and display total subtitle count and estimated number of batches.

3. **Processing & Real-Time Progress Section:**
   - "Start Translation", "Pause/Resume", and "Cancel" buttons.
   - A visual **Progress Bar** showing percentage completed (e.g., `45%`), current batch status (e.g., `Translating Batch 5 of 16...`), elapsed time, and estimated time remaining.
   - A live preview box showing the most recently translated subtitle blocks as they finish.

4. **Download Output:**
   - Once 100% complete (or even partially if paused), show a prominent **"Download Translated .SRT"** button that downloads the final UTF-8 encoded `.srt` file with `_Sinhala.srt` appended to the original filename.

### CRITICAL TECHNICAL & API IMPLEMENTATION RULES:
1. **Direct REST API Integration:**
   Make requests directly using `fetch` to the official Gemini REST endpoint:
   `POST https://generativelanguage.googleapis.com/v1beta/models/${selectedModel}:generateContent`
   Headers:
   - `x-goog-api-key`: `${apiKey}`
   - `Content-Type`: `application/json`

2. **100% Timestamp & Structure Preservation (Deterministic Parsing):**
   - Parse the uploaded `.srt` file in JavaScript into an array of objects: `{ index, timestamp, text }`.
   - NEVER rely on the AI to output timestamps, because LLMs sometimes skip or corrupt timecodes.
   - Instead, for each batch of 60 subtitles, send ONLY a JSON array or numbered list of `{ id: index, text: dialogue }` to the Gemini API.
   - Use `responseMimeType: "application/json"` in `generationConfig` so Gemini returns a clean JSON array of `[{ "id": index, "translatedText": "..." }]`.
   - Validate that every `id` in the chunk received a translation. Keep HTML tags like `<i>` and `</i>` intact.
   - Reconstruct the final `.srt` file in JavaScript using the original `index` and exact original `timestamp` paired with the new `translatedText`.

3. **Translation System Instruction:**
   Pass `systemInstruction` in the REST payload instructing Gemini:
   "You are an expert TV and movie subtitle translator. Translate the provided subtitle lines into natural, modern conversational [Target Language] (for Sinhala, use natural spoken Sinhala 'කතා බහේ සිංහල' suitable for movies/TV series, preserving slang, humor, and emotion rather than rigid literary Sinhala). Preserve any HTML tags like <i> or ♪. Return ONLY a valid JSON array matching the exact input IDs."

4. **Error Handling & Auto-Retry:**
   - If a request hits a `429 Too Many Requests` or network error, automatically wait 15 seconds and retry that specific batch up to 3 times before pausing.
   - Allow the user to manually click "Retry Failed Batch" without losing already translated batches.

Design the UI with a sleek, dark-mode cinema/media studio theme using Tailwind CSS and Lucide icons. Ensure everything works out-of-the-box in a single run.
